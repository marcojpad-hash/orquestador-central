# AGENTS.md — contrato transversal multi-modelo

Antes de trabajar en este repositorio:
1. Leer las [Reglas operativas universales](https://github.com/marcojpad-hash/orquestador-central/blob/main/docs/REGLAS_OPERATIVAS_UNIVERSALES.md).
2. Leer la [Arquitectura del coordinador central](https://github.com/marcojpad-hash/orquestador-central/blob/main/docs/ARQUITECTURA_COORDINADOR_CENTRAL.md).
3. Leer el [Contrato de trabajo multi-modelo](https://github.com/marcojpad-hash/orquestador-central/blob/main/docs/CONTRATO_TRABAJO_MULTI_MODELO.md).
4. Revisar el [Registro de capacidades verificadas](https://github.com/marcojpad-hash/orquestador-central/blob/main/docs/CAPACIDADES_MODELOS.md) y actualizarlo si la interfaz o los permisos cambiaron.
5. Leer este README y las instrucciones/contratos locales del proyecto.
6. Confirmar repositorio, rama, commit, permisos y alcance antes de escribir.
7. No declarar recepción, ejecución, pruebas o publicación sin evidencia observable.
8. Al terminar, releer desde GitHub los archivos modificados y dejar commit, rutas, pruebas y estado.

## Reglas específicas del orquestador
- Este repositorio contiene coordinación transversal, contratos, mapas y handoffs.
- No duplicar código ni artefactos canónicos de Motor U6 o CAPCOT.
- Mantener la matriz de capacidades basada en pruebas, no en suposiciones.
