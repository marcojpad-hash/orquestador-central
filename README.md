# orquestador-central
Orquestador central: núcleo, memoria compartida, registro de órdenes, enrutador de agentes.

## Inicio obligatorio para cualquier modelo
1. Leer [Contrato de trabajo multi-modelo](docs/CONTRATO_TRABAJO_MULTI_MODELO.md).
2. Declarar/actualizar capacidades en [CAPACIDADES_MODELOS.md](docs/CAPACIDADES_MODELOS.md).
3. Usar la [plantilla de handoff](docs/PLANTILLA_HANDOFF_MULTI_MODELO.md) para delegar trabajo.
4. Leer el contrato y README del proyecto específico antes de actuar.

El contrato transversal define arranque, asignación por capacidades, economía de tokens, permisos, seguridad, Git, handoffs y evidencia. Los contratos de cada proyecto siguen siendo autoridad para su código y entregables.
